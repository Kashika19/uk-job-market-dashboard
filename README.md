# UK Job Market Data Dashboard

> **Status:** In progress

An end-to-end portfolio project exploring the UK technology job market, with a focus on graduate and junior opportunities.

## Project goals

- Clean and standardise job-listing data
- Explore salaries, locations, working arrangements, and experience levels
- Identify frequently requested tools and skills
- Analyse wording related to Skilled Worker sponsorship
- Present useful findings in an interactive Power BI dashboard

## Planned toolkit

Python · Pandas · SQL · Power BI · Excel

## Planned repository structure

```text
data/          Sample or permitted datasets
notebooks/     Exploration and data-cleaning notebooks
sql/           Analysis queries
dashboard/     Power BI screenshots and documentation
reports/       Findings and recommendations
```

## Questions this project will explore

1. Which technical skills appear most often in graduate and junior roles?
2. Which UK locations offer the most opportunities?
3. How do advertised salaries vary by role and location?
4. How common are remote and hybrid working arrangements?
5. How frequently do listings mention sponsorship?
